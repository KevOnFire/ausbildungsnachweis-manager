# Ausbildungsnachweis-Manager

Ein Windows-Programm, mit dem du deine wöchentlichen Ausbildungsnachweise schreibst,
verwaltest und bei der IHK einträgst.

## Herunterladen

### ➜ [AusbildungsnachweisManager.exe herunterladen](https://github.com/KevOnFire/ausbildungsnachweis-manager/releases/latest/download/AusbildungsnachweisManager.exe)

Der Link liefert immer die neueste Version. Alle Versionen mit Änderungsliste findest du unter
[Releases](https://github.com/KevOnFire/ausbildungsnachweis-manager/releases).

> **Achtung:** Der grüne Knopf **„Code" → „Download ZIP"** oben auf dieser Seite lädt *nicht*
> das Programm herunter, sondern nur die Dateien dieser Seite. Nimm den Link oben.

## Quickstart

1. **Ordner anlegen** – z. B. `Ausbildungsnachweise` auf dem Desktop – und die
   heruntergeladene `AusbildungsnachweisManager.exe` hineinlegen.
2. **Starten** per Doppelklick. Falls Windows *„Der Computer wurde durch Windows geschützt"*
   meldet: **Weitere Informationen → Trotzdem ausführen**. Das kommt, weil die Datei kein
   kostenpflichtiges Signaturzertifikat hat.
3. **Einrichten** – beim ersten Start fragt ein kurzer Assistent nach Name, Beruf und
   Ausbildungsbeginn. Alles lässt sich später unter *Profil* ändern.
4. **Ersten Nachweis schreiben** – links auf *Nachweis erstellen*, die drei Felder ausfüllen
   und auf **Abgeben**. Mit *Als Entwurf sichern* kannst du jederzeit später weitermachen.
5. **Optional: bei der IHK eintragen lassen** – unten links auf deinen Namen klicken (*Profil*), dort Azubinummer und Passwort
   hinterlegen. Dann füllt das Programm beim Abgeben das IHK-Portal aus. Es füllt nur aus –
   auf *Speichern* klickst du im Portal selbst.

**Schon Nachweise bei der IHK?** Exportiere sie im IHK-Portal als PDF und zieh die Datei ins
Programmfenster – oder *Einstellungen → IHK-PDF importieren…*.

## Was das Programm kann

- Wochennachweise schreiben, als Entwurf sichern und abgeben
- Übersicht mit Fortschritt im Ausbildungsjahr, Kalender und Liste fehlender Wochen
- Halbautomatisches Eintragen ins IHK-Portal (tibros)
- Vorlagen für wiederkehrende Wochen, z. B. Betrieb Mo–Do, Berufsschule Fr
- Frühere Fassungen jeder Woche mit eigenen Notizen
- Import und Export als PDF
- Erinnerung per Windows-Benachrichtigung, automatische Sicherungen
- Rechtschreib- und Grammatikprüfung (optional, richtet sich auf Klick selbst ein)

## Wo liegen meine Daten?

Deine Nachweise liegen als einfache Textdateien in dem Ordner, den du beim Einrichten
wählst – lesbar auch ohne dieses Programm. Einstellungen und Entwürfe liegen unter
`%APPDATA%\AusbildungsnachweisManager`. Das IHK-Passwort wird verschlüsselt und nur auf
deinem PC gespeichert.

## Updates

Das Programm sucht beim Start selbst nach neuen Versionen und spielt sie auf Klick ein.
Updates sind signiert: Eingespielt wird nur, was nachweislich vom Entwickler stammt.
Nach einem Update zeigt das Programm kurz, was sich geändert hat.
